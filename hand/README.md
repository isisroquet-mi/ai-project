# Derivaciones manuscritas

`01-derivacion-manual-Rp.pdf` es la hoja original de Isis sobre la derivada
de la variación de costos $R=\log(K^A/K^V)$ respecto de $p$. Muestra la
regla de la cadena, la derivada de ambos costos, la condición para
$R_p>0$ y el caso en que $\kappa_p^V=0$.

La hoja conserva su encabezado original «Proposición 1», aunque el
cálculo de $R_p$ corresponde a la comparativa vinculada con la
Proposición 2 de `slides/final.tex`. El archivo no sustituye las otras
demostraciones manuscritas que se requerirán para el trabajo final.
